# XToolpro 审阅预览

以下页面均独立加载设计令牌，供设计评审按主题检查：

- `index.html`：预览目录与快速索引。
- `colors.html`：基础色、语义状态与交互表面。
- `type-spacing.html`：字体层级、等宽数据和间距尺度。
- `radius-shadows.html`：8px、10px、12px 圆角及对话框层级。
- `components.html`：任务行与设置行的结构和状态。
- `surfaces.html`：边框、焦点与可交互组件表面。
- `assets.html`：保留的应用图标与维护者头像。
- `applied-ui.html`：首页、工具卡与任务状态的组合应用。

预览只使用项目本地资源和 `../colors_and_type.css`。
