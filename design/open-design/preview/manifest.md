# 预览清单

| 文件 | 审阅焦点 | 来源证据 |
| --- | --- | --- |
| `index.html` | 所有聚焦预览的入口 | 共享令牌与包导航 |
| `colors-primary.html` | 主色、语义色与状态配对 | 原型 `:root`、品牌规范 |
| `colors.html` | OKLch 色彩与状态配对 | 原型 `:root`、品牌规范 |
| `themes.html` | 浅色与深色角色令牌、状态与操作对比 | 原型 235 色相、共享主题令牌 |
| `typography-specimens.html` | 标题、正文、等宽数据层级 | 原型排版规则 |
| `type-spacing.html` | 平台字体、等宽数值、4px 尺度 | 原型排版规则 |
| `spacing-tokens.html` | 4px 间距、内容边距与触控尺寸 | 原型移动端布局 |
| `radius-shadows.html` | 8/10/12px 圆角与对话框提升层级 | 原型表面与对话框样式 |
| `components-buttons.html` | 主次按钮、文本按钮、焦点态 | 原型交互样式 |
| `components.html` | 工具、任务、状态与设置行 | 原型交互样式 |
| `surfaces.html` | 按钮、焦点与组件表面 | 原型交互样式 |
| `assets.html` | 应用图标、维护者头像 | 已复制原始资产 |
| `applied-ui.html` | 首页、工具、任务的真实组合 | 原型与功能需求文档 |

所有预览均为静态审阅载体；完整的交互行为见 `../source_examples/xtoolpro-mobile-prototype.html` 与 `../ui_kits/app/index.html`。
