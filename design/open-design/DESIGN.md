# XToolpro 设计系统

> 来源摘要：本规范从 `source_examples/xtoolpro-mobile-prototype.html`、`brand-spec.md`、`XToolpro-功能需求文档.md` 与保留资产中提取，服务 Android 手机和平板上的本地优先工具箱。

## Context / 产品语境

XToolpro 是面向 Android 手机与平板的本地优先工具箱，整合代理连接、设备维护、公开链接媒体提取与图片处理。设计的首要任务是让用户在高频操作和高风险操作中都能快速读懂状态、文件影响与下一步。

核心产品表面是首页存储与连接概览、工具箱网格、统一任务中心、设置列表，以及代理、清理、媒体和图片四个功能模块。功能需求明确要求清理前预览、任务可暂停/恢复/重试、按需申请权限和本地优先处理。

## 视觉基础

界面使用接近白色的冷调阅读底、深灰蓝文本、细弱边界与单一天空蓝强调。页面保持中等信息密度，模块主要通过分隔线、网格和留白组织，而不是连续堆叠浮层卡片。蓝色仅用于可执行、已选中与已连接状态；成功、警告和失败必须同时配合清晰文案、图标或状态标签。

## Color / 色彩

完整令牌在 `colors_and_type.css`。六个基础令牌为：`--bg`、`--surface`、`--fg`、`--muted`、`--border`、`--accent`，均来自原型和既有 `brand-spec.md`。实现必须优先消费角色令牌，不让组件直接耦合基础色：`--canvas`、`--surface-raised`、`--surface-selected`、`--text-primary`、`--text-secondary`、`--border-interactive`、`--action-primary` 与 `--status-*` 构成稳定的组件契约。

- 页面底色：`--bg`；可承载内容的表面：`--surface`。
- 常规文字：`--fg`；辅助文字与元数据：`--muted`。
- 主要操作、选中导航与进行中进度：`--accent`。
- 连接成功：`--success`；需要注意：`--warn`；失败及重试：`--danger`。
- 悬停使用 `--accent-soft`，按压使用 `--accent-hover` 或 `--accent-pressed`；不可通过降低前景对比度作为悬停反馈。

色彩证据来自原型与 `brand-spec.md` 的 `:root`，所有派生色使用 OKLch 混合，fallback 仅供旧审计工具读取。

### 明暗主题

默认主题为浅色。`[data-theme="dark"]` 使用同一 235 色相、天空蓝操作色和成功/警告/失败语义重新平衡亮度；它是为阅读环境补齐的系统套件，不假称为源项目的已交付深色页面。主题切换只改变令牌，组件不得覆盖其中的表面、文字、边框或状态颜色。入口可将选择保存为 `localStorage`，但系统主题不可作为改变连接、权限或任务事实的理由。

## Typography / 字体

显示与正文均使用平台系统字体栈，以 Android 和系统 UI 的可读性为优先。页面标题为 26-34px / 1.15、690 权重；区块标题为 17px / 1.25、670 权重；正文为 14px / 1.45。容量、进度、时间、版本和任务标识使用 `--font-mono`，常规为 12px / 1.4；标签可用 11px 等宽大写字距。等宽层只承载可扫读的事实，不用于长段说明。

没有提供原生字体文件，因此不引入外部字体；显示与正文沿用平台系统字体，数字与任务元数据使用等宽栈。

## Spacing / 间距与形状

使用 4px 基础尺度：4、8、12、16、20、24、28、32px。移动端内容左右留白为 18px，小屏可降至 15px；常规区块间距为 28px；卡片内距为 14-22px。基础圆角为 8px，筛选容器可用 9px，编辑工具条可用 10px，对话框可用 12px。触控目标不小于 44px，Android 实现建议不小于 48dp。

阴影只用于对话框等需要建立前后关系的表面；常规列表和工具网格使用边界线与留白，不用阴影堆叠。

## Layout / 布局

顶部栏固定在可达区域，高度 70px，底部采用四项固定导航：首页、工具、任务、设置。主内容在手机上采用单列，快速工具为两列；工具网格按可用宽度扩展至三至四列，宽卡片跨两列。大屏容器最大 1120px 并使用细边线建立应用边界。任务、设置和工具分组优先采用连续列表及区块分界，避免“卡片套卡片”。

## Components / 组件

### 顶部栏与导航

品牌图标为 31px 圆角图形。图标按钮为 44px 方形、8px 圆角、细边框。底部导航每项最小高度 52px，活动项使用天空蓝并加强图标笔画；标签保持 11px。

### 工具卡片

工具卡片有紧凑和宽卡片两种尺寸，最低高度分别为 104px 和 102px。图标放在 34px 的浅蓝方形容器内。卡片必须同时呈现图标、工具名称和一句明确副标题；收藏操作独立放在右上角，不影响启动入口。

### 按钮与筛选

主按钮使用 `--action-primary` 与 `--text-on-accent`、44px 高；一个操作流同屏只有一个主按钮。次要按钮使用 `--surface-raised`、`--border-subtle` 与 `--text-primary`；文本按钮无边框但保持 44px 触控区。悬停分别使用 `--action-primary-hover` 或 `--surface-hover`，不得降低文字对比度。筛选使用包裹容器加内部选中面，不将每个选项做成独立胶囊。所有焦点态为 3px `--focus-ring` 外轮廓。

### 状态、进度与任务

状态点直径 8px，必须与文字一起出现。进度条使用浅色轨道和填充型进度，首页存储使用 9px，任务使用 5px。任务行以图标、名称、状态元数据、进度和单一行末动作构成；失败任务仅用危险色点出需要处理的动作，不把整行变红。

### 设置、提示与对话框

设置项采用 64px 左右的连续列表行，可包含 35px 功能图标、简短说明、箭头或开关。一次性提示使用细边框说明条。高风险操作使用底部对齐的确认对话框，标题、影响说明、取消和唯一的确认主操作缺一不可。

## Motion / 动效与反馈

默认动效为 150-220ms 的 `cubic-bezier(.2, 0, 0, 1)`，仅用于页面切换、分组展开、按压和状态更新。任务进度平滑更新但不得循环装饰。减少动态效果开启时，所有非必要动效降为即时或 10ms。动效必须可中断，不能延迟取消、高风险确认或导航。

原型中的任务暂停/恢复、筛选切换、布局确认和提示均为即时可中断操作；动效只承担状态变化的可读性，不制造等待。

## Voice / 文案语气

使用冷静、直接、说明性的简体中文。先说事实，再说影响和下一步，如“VPN 已连接”“网络连接已中断”“清理前展示完整预览”。按钮使用清晰动词，不使用营销式承诺；风险操作说明会指出文件、权限或布局影响。不承诺匿名、绝对安全、无风险清理或绕过访问限制。错误不展示堆栈，需给出可理解的原因与可执行的恢复入口。

## Anti-patterns / 反模式

- 不使用多层渐变、装饰性光球、拟物插画或与工具任务无关的摄影。
- 不将每一段内容包在悬浮圆角卡片内，不使用超过 12px 的常规圆角。
- 不以颜色作为唯一状态表达，也不让失败色扩散成大面积背景。
- 不在同一视口放置多个相同主操作，或以低对比度灰字作为悬停状态。
- 不裁切任务、容量、路径或设置描述；小屏重新排布，不横向挤压。
- 不伪造任务、连接、存储或清理结果；无数据时使用明确空状态。

## 证据边界

本系统从 `xtoolpro-mobile-prototype.html`、`brand-spec.md`、功能需求文档和复制资源中提取。未提供 Android 原生字体文件、运行时图标包或深色模式成品，因此包内保留平台字体栈和原型图标语言，不把这些未验证内容扩展为新品牌资产。

## 复用入口

先加载 `colors_and_type.css`，再从 `ui_kits/app/index.html` 取应用壳和交互状态，从 `ui_kits/app/components.html` 取组件结构；用 `preview/` 逐项核对令牌、间距、形状、组件、资产、主题和组合表面。复用时先绑定角色令牌，再替换真实数据；不要复制演示中的连接、存储或任务结果。
